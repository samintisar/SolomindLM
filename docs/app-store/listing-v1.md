>
> SIGN IN: Use the demo account above, or Sign in with Apple. The demo account already has a notebook with sources and generated content.
>
> HOW TO TRY IT: Open the notebook on the home screen. Ask a question in Chat, or open Studio and generate Flashcards.
>
> ACCOUNT DELETION: Tap the avatar (top right) → Delete account. Type DELETE to confirm. This permanently deletes the account and all its data, and cancels any subscription.
>
> PURCHASES: The iOS app offers no purchases and contains no links to buy anything. Some users subscribe on our website; those users simply have higher usage limits in the app (guideline 3.1.3(b)).
>
> CONTENT: Generated content is created only from sources the user uploads. Users can share a notebook by private link. Users can report community prompt templates.
